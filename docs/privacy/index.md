# 隐私说明

经您允许后，本网站使用 Google Analytics 了解页面访问量、访问来源和网站使用情况。Google Analytics 可能使用 Cookie，并收集页面地址、设备与浏览器信息、近似地理位置及页面互动等数据。相关数据由 Google 处理；Google 的数据处理方式请参阅 [Google 隐私权政策](https://policies.google.com/privacy)。您可以通过页面底部的“统计设置”更改选择；拒绝后网站不会加载统计代码。

您可以通过浏览器设置限制或清除 Cookie，也可以使用 [Google Analytics 停用浏览器插件](https://tools.google.com/dlpage/gaoptout)限制数据收集。
